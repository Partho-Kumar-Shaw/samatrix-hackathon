ABOUT THE PROJECT

AI for Better Wi-Fi Resource Planning

WiFiPredict is a Machine Learning solution designed to predict daily network bandwidth usage across different campus zones.

The model considers contextual factors such as academic schedules, events, connected device patterns, packet loss and historical bandwidth usage.
